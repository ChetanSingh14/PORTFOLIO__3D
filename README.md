# 🚀 Chetan Singh — 3D Developer Portfolio

A high-performance, modern 3D Developer Portfolio built with **React**, **Three.js**, **React Three Fiber**, **Framer Motion**, and **Tailwind CSS**. It showcases Chetan Singh's full-stack and mobile engineering achievements, production work experience, DevSecOps AI projects, technical skills, and academic accomplishments.

---

## ✨ Features

- **🌐 Interactive 3D Graphics**: Rendered using Three.js & React Three Fiber (`ComputersCanvas`, `BallCanvas`, `EarthCanvas`, `StarsCanvas`).
- **🎯 Dynamic Custom Cursor**: Trailing mouse follower dot with expand effects over interactive elements.
- **💼 Work Experience Timeline**: Comprehensive history covering Insanger Technologies, Times Internet, FnMafia Technologies, AY Tech, and Open Source contributions (Summer of Bitcoin, GSSoC, Hacktoberfest) with custom company brand logos.
- **🚀 Featured Projects & Category Filtering**: Interactive project cards showcasing *DevSecOps AI Code Reviewer*, *UecoHub*, *Cab Booking Application Clone*, *DEV_QUERY*, and *Hospital Appointment Management System (HAMS)* with live demo & GitHub repository links.
- **🎓 Education & Achievements**: Highlights Polaris School of Technology (B.Tech in Computer Science), 100+ LeetCode/GFG Graph Theory DSA problem solving, Open Source awards, and Hackathon top rank.
- **📩 Direct Contact Integration**: Interactive form configured to deliver messages directly to `siradhanachetan14@gmail.com`.
- **🎨 Glassmorphic & Responsive Aesthetics**: Sleek dark mode design system built with custom gradients and Tailwind CSS.

## 🚀 Getting Started

### Prerequisites

Ensure you have **Node.js (v18+)** and **npm** installed on your machine.

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/ChetanSingh14/PORTFOLIO__3D.git
   cd PORTFOLIO__3D
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```
